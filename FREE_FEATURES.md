# MotivaAI — free-first development plan

## Added in this build
- Offline mystery-topic list and daily topic selection.
- Local history to avoid exact topic repeats.
- Hindi script drafts from local templates.
- Read-aloud through Android's installed text-to-speech engine.
- Manual topic entry.
- No paid API key is required for these features.

## Limitations
- Script generation is template-based, not a full generative AI model. Fact-check and edit before publishing.
- Hindi TTS voices depend on voices installed on the phone. Male/female availability cannot be guaranteed on every device.
- 5–10 minute 1080p MP4 rendering is not included yet.
- GitHub Actions builds APKs; it is not a free always-on AI video server.
- Daily automatic generation while the phone is off requires scheduled background processing or a backend. Free hosting has quotas and cannot be promised as unlimited.

## Next milestones
1. Save/export scripts and add topic library.
2. Add subtitles, original/licensed visuals and audio.
3. Add on-device video rendering and 1080p MP4 export.
4. Add daily local reminder and scheduled on-device generation.
5. Keep YouTube upload manual, with preview and user approval.
